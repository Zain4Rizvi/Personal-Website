## Problem

Match telemetry is dense and hard to read by eye. Players want answers to questions about a match, not a spreadsheet.

{/* TODO: telemetry source (replay parser), match volume, who it is for */}

## Approach

Drop in a Rocket League .replay file and the app prepares its telemetry and opens an interactive 3D simulation. A LangChain agent with tool calling answers natural-language questions ("Why did we concede the third goal?") by calling functions over that telemetry. The Dockerized dashboard stays synced to playback, with controls for follow-ball, coverage, centroid and pressure overlays.

## Key technical decision

Let the model call typed tools over the telemetry instead of reading it as text, so answers come from computed values.
