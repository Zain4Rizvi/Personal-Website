## Problem

Build the rendering pipeline from scratch: no graphics library, only rays, intersections and lighting maths.

## Approach

Rays are cast per pixel against transformed ellipsoids and a plane. Each hit is lit with the Phong model (ambient, diffuse, specular) and extended with shadows and recursive reflection. The four figures above split the final image into its parts.

## Key technical decision

Objects are unit primitives with a transform matrix and its stored inverse, so intersection runs in object space and any scaling, rotation or translation costs one matrix multiply per ray.

## Result

A 512 x 512 render of two ellipsoids and a floor with shading, reflections and shadows. It is a native program, so the site shows its output rather than running it.

## Build it

```bash
cd "Light Raytracer"
gcc -O2 -o RayTracer RayTracer.c utils.c svdDynamic.c -lm
./RayTracer 512 3 0 out.ppm    # size, recursion depth, antialias 0/1, output file
```
